Firmware

Planned

Firmware is a project-wide effort rather than a machine of its own: one place for everything firmware-related across the whole fabrication line.

Its folder is set up to hold a parts list for firmware-specific hardware — microcontrollers, breakout boards, connectors — with any component a machine shares tracked in that machine's own parts list instead; a requirements document listing what the rest of the project expects firmware to handle; a high-level design written to be readable by an engineer with no firmware background; and low-level design documents covering schematics, sequence diagrams, state machines and pin assignments. The requirements document is still empty and none of the design documents have been written yet. Code and code documentation are kept in a GitHub repository rather than in Drive.
