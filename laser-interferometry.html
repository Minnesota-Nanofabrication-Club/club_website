Laser Interferometry

Architecture design

The project folder holds a system overview describing the proposed architecture and two diagrams, rather than a record of assembly.

What It Does

A maskless lithography stepper exposes a projection field smaller than the wafer, so the substrate has to be stepped from field to field precisely. This metrology system is intended to provide real-time, high-speed closed-loop position feedback for the XY stage, to remove stitching errors between exposure fields and to allow precise alignment during probing and testing.

The proposed architecture is a heterodyne interferometer rather than a homodyne one, which the overview prefers because a homodyne design is susceptible to DC noise. Its light source is a Zeeman-split helium–neon laser: applying a magnetic field to a standard HeNe tube splits its output into two distinct optical frequencies, and the difference between them is what the measurement is read against.

Two machines are named as the places it plugs into. On the stepper, the interferometer feeds position data directly to the motion controller, so that when the stage overshoots a move the software can digitally shift the pattern to align the exposure with the previous field. On the probe station, the same software can command sub-micron step-and-repeat moves between dies, so the test probes land squarely on the metal contacts.

Subsystems

  • Light source — a Zeeman-split HeNe laser producing two known optical frequencies.
  • Optical path — a beam splitter sends one frequency to a fixed reference reflector and the other to the reflector that tracks stage movement; the two are recombined at an optical receiver.
  • Signal processing — an ESP32 reads the receiver, handling the expected low-megahertz beat frequencies, and passes the data to a PC running custom software.
