Laser Interferometry

Architecture design

The project folder holds a written system overview and a bill of materials. The architecture has been chosen and described; the timeline has not yet been broken into set dates, and lists what a working demonstration still needs — the heterodyne laser itself, a laser controller, a heater for the laser, the optical setup, and software.

What It Does

This is a measurement system for the fabrication line rather than a processing tool. In maskless photolithography the projection field is smaller than the wafer, so the substrate has to be stepped across it precisely. The interferometer is intended to provide real-time, high-speed closed-loop positional feedback for the X–Y stage, eliminating stitching errors between exposure fields and allowing precise alignment during probing and testing.

Subsystems

The proposed architecture is a heterodyne interferometer rather than a homodyne one such as a Mach–Zehnder, which is susceptible to DC noise.

  • Light source — a Zeeman-split helium–neon laser. Applying a magnetic field to a standard HeNe tube splits its output into two distinct optical frequencies.
  • Optical path — a beam splitter sends one frequency to a reference reflector and the other to a measuring reflector that follows the stage. The two are recombined at the optical receiver, and the shift in the returned beat frequency against the laser's own is what encodes the mirror's movement.
  • Signal processing — an ESP32 handles the two beat frequencies, expected in the low megahertz, and sends the data on to a PC through custom software.

Integration

  • Maskless stepper — the interferometer feeds position data directly to the motion controller. If the stage overshoots a movement, the software can digitally shift the pattern so the exposure still aligns with the previous field.
  • Probe station — the same software can command sub-micron step-and-repeat moves between dies, so that test probes land squarely on the metal contacts without scratching the surrounding layers.
